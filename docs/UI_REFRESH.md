# Shade: обновление интерфейса

Дата: 14 ноября 2026. Ветка: `codex/shade-hackathon-readiness`.

## Изменения

- Чёрно-белая палитра: графитовые поверхности, серые аватары, светлые исходящие сообщения с тёмным текстом и единые скругления. Красный оставлен для ошибок.
- Экран входа: перерисованный белый призрак с крупными глазами и улыбкой, новое расположение формы и типографика, доступное описание хранения истории, понятное состояние загрузки.
- Главный экран: список переписок, настоящий локальный поиск по никнейму и превью последнего сообщения, фильтр «Избранное», кнопка создания разговора.
- Профиль: имя, никнейм, email/аватар при их наличии, существующий выход с подтверждением.
- Новый разговор: поиск по никнейму, состояния ожидания, ошибки и найденного профиля.
- Переписка: спокойный фон, новые пузырьки, разделители дат, подсказки к квитанциям, компоновка ответа и новая панель вложений.
- Убрано бесконечное пульсирующее свечение редактора сообщения.
- Генерация ключа базы вынесена в фоновый isolate: 2,1 млн итераций PBKDF2 больше не блокируют первый экран. Формат ключей и параметры сохранены.
- Восстановлены три настоящих файла Roboto: прежние `.ttf` содержали HTML. Добавлены лицензия и источник.

## Проверки

- `flutter test --reporter expanded --timeout 60s`: **18/18**, включая криптографию, миграцию SQLite и сохранение очереди, валидацию входа и новые UI-проверки.

Ранее созданные изменения авторизации, сервера, шифрования и очередей сохранены. В рамках визуального обновления они не выдаются за завершённый продукт. Коммит и push этой доработки не выполнялись.

## Ограничения

- Google OAuth в облаке и вход на настоящем телефоне в этой итерации не подтверждены.
- APK настроен на локальный relay Android Emulator: `https://10.0.2.2:3443`. Без сервера/OAuth это сборка для визуальной проверки экрана входа, а не настроенный интернет-мессенджер.
- Debug APK подписан отладочным ключом; это не пакет для Google Play.
- Текущий Flutter 3.38.10 требует minimum Android API 24. Поддержка API 23 из исходного ТЗ пока не завершена.
- Не добавлены фиктивные вызовы, голосовые сообщения, группы или показатели онлайна.
- Для презентации нужны реальные участники и подтверждённая демонстрация переписки.
