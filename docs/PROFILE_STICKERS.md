# Профили и коллекция Shade

Ветка `codex/profile-sticker-collection`, база `ceaa1d1`. Для работы подарков клиент и сервер должны быть из этой ветки. Запуск relay описан в README. Профиль открывается с аватара на главном экране, профиль контакта — из шапки чата. Секция подарков находится под шифрованием. Чтобы положить подарок на стену, откройте «Оформить», выберите наклейку в лотке, переместите её и нажмите «Готово». Отдельное нажатие в режиме просмотра открывает осмотр. Движение за центр наклоняет винил, от края внутрь — загибает.

## API

Все методы используют middleware `requireUserAuth`, заголовки `x-username` и `x-session-token`. Сервер получает автора из `req.auth.username`.

| Метод | Параметры и результат |
|---|---|
| GET /user/:username/stickers | Возвращает displayName, revision, wall и коллекцию публичных пар giftId/stickerId. Включает неразмещённые виды для книжки. Записка и даритель доступны только получателю. |
| GET /stickers/inventory | Инвентарь получателя с fromUsername, note, receivedAt в миллисекундах Unix, текущей версией и стеной. |
| POST /stickers/gift | toUsername, stickerId, note до 240 символов UTF-16 и requestId длиной 16–80. Возвращает giftId после записи. Повтор того же запроса возвращает тот же giftId. Изменённая нагрузка с тем же идентификатором получает 409. |
| PUT /stickers/wall | revision и массив wall до 32 элементов. Каждый элемент содержит собственный giftId, xNorm/yNorm от 0 до 1, rotation в радианах от −π до π, scale от 0.5 до 2 и zIndex от 0 до 31. Успех возвращает wall и следующую revision. Устаревшая версия даёт 409. |
| PUT /profile/name | displayName длиной 1–64 после trim. Меняет отображаемое в профиле имя, сохраняя сетевой никнейм. |

Каталог содержит четыре авторских рисунка с ID orbit, moth, comet, ghost. Подарки бесплатные. Размещение добровольное. До восьми отправлений за минуту, 2000 полученных и 10000 идентификаторов отправок на пользователя. Ответы 400/404/409/413/429/503 показывают отказ валидации, отсутствующего пользователя, конфликт, размер, лимит или ошибку записи. Частные записки зашифрованы при хранении средствами существующего relay. Relay читает их при обработке. Шифрование сообщений в чатах работает отдельно.

Хранилище подарков — отдельная зашифрованная карта пользователей в DATA_DIR/stickers.json. Это позволяет записывать историю отправителя и инвентарь адресата одной атомарной заменой файла. Сервер сериализует изменения и публикует новое состояние в памяти после успешной записи. Архитектура рассчитана на один процесс relay на DATA_DIR. Добавьте этот файл в резервное копирование вместе с существующим SESSION_SECRET.

## Миграция и рендеринг

Версия базы клиента 7 добавляет verified_keys с первичным ключом (owner,peer). Старое подтверждение из SharedPreferences переносится при просмотре контакта, а прежняя запись удаляется после транзакции. При смене отпечатка строка помечается неподтверждённой до следующей ручной сверки. На мобильном устройстве используется существующая SQLCipher. Тест перехода с v6 использует SQLite FFI, проверяет историю, повторное открытие, разделение владельцев и возврат прежнего ключа после замены.

Рисунки создаёт CustomPainter. Runtime-шейдер client/shaders/holo_sticker.frag получает размер, время и наклон. При недоступности шейдера остаётся градиентный блик. Для загиба принт разделён на 32 полосы с проекцией на полуцилиндр и тенью. Это геометрическая аппроксимация винила. Свободные диагональные складки не моделируются. При уменьшении анимаций выключены покачивание и пружинный возврат.
