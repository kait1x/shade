# Профиль Shade — продолжение работы Opus

Сохранён существующий `ProfileScreen`. Компоновка приближена к предоставленному изображению: компактнее шапка и карточки, тонкие рамки, янтарный акцент для сверки, собственный ключ и ключ собеседника различаются подписями.

- Собственный профиль: аватар, имя, никнейм, email при наличии, информация об устройстве, показ/копирование публичного fingerprint и существующий выход.
- Профиль собеседника: существующие сообщение/копирование/локальная заметка, статус с relay, состояние ручной сверки.
- Сверка: полный SHA-256 код и identicon, копирование и кнопка «Ключ совпадает». Подтверждение сохраняется локально для пары аккаунт/контакт и именно этого fingerprint. Новый ключ не получает отметку автоматически. Изображение не выдаётся за QR-код.
- Убрано абсолютное утверждение, будто одно совпадение кода гарантирует отсутствие перехвата. Подпись теперь описывает сравнение и область подтверждения.
- Кнопки редактирования/дополнительного меню из превью не имитируются: неподключённые действия не добавлены.

`artifacts/ui/profile-showcase.png` — рендер реальных Flutter-компонентов в декоративных рамках телефонов. Аккаунты, email, время, ключи, заметка и онлайн-статус — тестовые fixtures, не данные настоящей сессии. Оригинальная картинка Opus сохранена пользователем отдельно; HTML/SVG-источник в папке проекта не найден.

Проверки: полный набор Flutter — 31/31; профиль включает отдельные проверки сохранения сверки, смены ключа (в том числе при уже открытой сверке), изоляции по владельцу, экрана 320×640 со шрифтом 1.4. Анализатор — No issues found. Логи: `artifacts/ui/profile-all-tests.txt`, `profile-preview-test.txt`, `profile-analyze.txt`, `profile-build.txt`.
