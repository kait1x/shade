# 🎬 Демо-видео Shade — сценарий (1 мин 40 с)

Цель: за 100 секунд показать живой путь пользователя на **настоящем staging**
https://alpha.shadechat.ru и доказать, что это не макет: два реальных устройства,
реальная сеть, реальное шифрование. Видео вставляется в презентацию (слайд
«Демонстрация») и живёт отдельно файлом `shade-demo.mp4`.

## Подготовка (за день до записи)

- [ ] Staging отвечает, вход через Google работает с обоих аккаунтов.
- [ ] Два устройства: **Samsung Galaxy A31** (Android Chrome, PWA «на экран Домой»)
      и **iPhone** (Safari, PWA). Оба аккаунта заранее зарегистрированы, ключи
      сверены (чтобы не тратить эфир на сверку — она уже была).
- [ ] Заранее заготовлено фото для отправки (нейтральное: кот / пейзаж).
- [ ] Запись экрана: Android — встроенная запись экрана; iPhone — Control Center.
      Пишем ОБА экрана отдельно, монтируем side-by-side или последовательно.
- [ ] Уведомления и личные данные на экранах скрыть (режим «не беспокоить»,
      тестовые аккаунты, никаких реальных переписок в кадре).
- [ ] Звук: закадровый голос владельца (живой, не синтез), тихая музыка не нужна.

## Правила записи

1. **Никаких секретов в кадре**: пароль-фразы не вводить на камеру (разблокировка
   Face ID / заранее разблокированная сессия), recovery-фразу не показывать,
   URL с токенами не светить.
2. Каждый дубль проверять: сообщение реально дошло до второго устройства
   (не «показалось»). Если staging моргнул — перезаписать, не монтировать обман.
3. Курсор/пальцы не должны перекрывать галочки статусов — крупный план статуса
   в момент 0:26–0:36 обязателен: это доказательство «прочитано» для жюри.
4. Темп речи спокойный; если не укладываешься — режь кадр 8, а не тараторь.
5. Экспорт: 1080p, mp4, H.264; в презентацию встроить файл + запасная ссылка.

## Запасной план (если staging недоступен в день записи)

Локальный запуск: `node --env-file=alpha.env alpha.mjs` + два браузерных профиля
на одном компьютере (Edge + WebKit/Chrome) — сценарий тот же, кроме Face ID
(кадр 1 заменяется на ввод парольной фразы, БЕЗ показа самой фразы — ввод за
кадром или монтаж). Честно сказать в видео: «демо на локальном сервере, staging
живёт по ссылке».
